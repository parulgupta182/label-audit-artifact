# Data Availability

This artifact includes aggregate result tables and anonymized sample files.

The full materialized vulnerable source-code corpus is not redistributed in this artifact because files originate from many upstream repositories with heterogeneous licenses. Instead, the artifact provides the scripts needed to reconstruct the corpus from public CVE/GitHub references and sample data for validating the analysis pipeline.

Raw Semgrep Pro JSON outputs are not included. The artifact includes aggregate outputs and parsed/evaluation-level examples.
